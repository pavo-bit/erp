# SSVM ERP Release Criteria

Updated: 2026-10-31

Release status: **BLOCKED / NOT PRODUCTION READY**.

Release requires all approved requirements to be `VERIFIED`, no unresolved critical/high security issues, successful cross-school tests, correct financial integrity tests, seven frontend builds, backend lint/type/build, clean install, migrations, full critical E2E, protected monitoring, and demonstrated backup restoration. Credential owners must rotate exposed values and confirm production secrets, gateway, TLS, DNS and infrastructure. School owners must approve financial/business rules and user acceptance.

The exact weighted score cannot be computed until the owner approves the full requirement inventory and point weights. A code-derived register is in `FEATURE_REQUIREMENTS.md`; it is not a scope freeze.
